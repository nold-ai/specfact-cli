## Probe API contract

`Manifest.load(path)` returns the frozen validated manifest. Its public string fields used by the probe tests are `repository`, `main`, `old_head`, `branch`, `main_tree`, `probe_tree`, `probe_path` and `probe_content`. `MANIFEST_SHA256` names the pinned manifest digest. `RunContext.from_env(env, stage, expected_executor)` validates the supplied environment and returns the frozen context. Policy refusals raise `ProbeRefusalError`, a dedicated Exception subclass.

`Probe(manifest, context, api).run()` returns a typed probe receipt. The API boundary provides `request(method, path, body=None)` with JSON object inputs and outputs; only the approved routes and methods are permitted. `GitHubAPI(token, output)` implements that boundary and owns ordered raw response persistence. `main(argv)` returns an integer exit status and persists the receipt on success or refusal. Receipt fields are `status`, `manifest_digest`, `context_verified`, `context`, `objects`, `ci_anchor_verified` and `root_anchor_verified`. The context records run ID, attempt, executor SHA, repository, actor, event, ref, workflow ID and workflow path. Each verified object records its SHA and `signed_object_verified` fact with the exact signed intent described above.
