## Decision

Normalize external Click context annotations during the existing parameter discovery step. Typer owns parameter conversion and context injection, which lets core remove its patch of the converter and preserve the existing option metadata for the root command and module installation.

Authenticate the released module files first. Recognize inactive caches by their name and bytecode header, and require an authenticated source file for each. Continue to compare active standard caches against trusted compiler output.
