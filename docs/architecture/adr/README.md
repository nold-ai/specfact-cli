# Architecture Decision Records

Use ADRs to document non-trivial architecture decisions.

## How to add a new ADR

1. Copy [template.md](template.md)
2. Create the next numbered file (`0002-...`, `0003-...`)
3. Set status (`Proposed`, `Accepted`, `Superseded`)
4. Link related OpenSpec change IDs
